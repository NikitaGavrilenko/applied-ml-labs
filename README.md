# Прикладные задачи машинного обучения

Общий репозиторий лабораторных. Каждая работа находится в своей папке со своими зависимостями, данными, кодом, результатами и инструкцией запуска.

| Работа | Тема и инструкция | Итоговый отчёт |
|---|---|---|
| 01 | [LLM и MIRACL ru](labs/lab01-llm-miracl/README.md) | [Word](labs/lab01-llm-miracl/report/Lab1_MIRACL_final.docx), [PDF](labs/lab01-llm-miracl/report/Lab1_MIRACL_final.pdf) |
| 02 | [Мультимодальный финансовый прогноз](labs/lab02-multimodal/README.md) | [Word](labs/lab02-multimodal/report_lab2.docx) |
| 03 | [Мультиагентное обучение для поиска](labs/lab03-marl-agentic-search/README.md) | [Word](labs/lab03-marl-agentic-search/report_lab3.docx) |

## Структура

```text
applied-ml-labs/
  README.md
  labs/
    lab01-llm-miracl/
    lab02-multimodal/
    lab03-marl-agentic-search/
```

Внутри каждой работы находятся README, requirements.txt, исходный код и артефакты. Имена готовых отчётов сохранены. Методички находятся рядом со своей работой в локальной копии.

## Запуск

Перейдите в папку нужной работы, установите её зависимости и выполните `python run_all.py`. Требования к локальным моделям и отдельные этапы приведены в README работы. Для проверки готовых результатов не обязательно повторять обучение.

## Следующие работы

Создавайте `labs/lab04-<topic>`, `labs/lab05-<topic>` и далее; добавляйте строку в таблицу выше. Для каждой работы нужны отдельные README, зависимости, код и результаты. Общие данные и универсальный ML-пайплайн заранее не создаются. Новая работа не вкладывается в предыдущую и не содержит собственного Git-репозитория.

Git-команды выполняются из корня `applied-ml-labs`. Большие веса, окружения, сырые архивы и временные файлы исключаются через `.gitignore` соответствующей работы. Для данных сохраняются источники, версии, лицензии и контрольные суммы.
