# Анализ ограничений поиска после фиксации модели

На test хотя бы один положительно размеченный документ содержался в объединении трёх поисковых выдач для 30 из 150 запросов (20%). Это верхняя граница Hit для данной фиксированной системы кандидатов относительно известных qrels: выбор политики не может найти документ вне выдачи. Подсчёт выполнен после выбора модели по validation; он не использовался для настройки поиска или выбора модели. Отсутствие положительной оценки не доказывает нерелевантность документа.

Примеры test для выбранного Independent REINFORCE, seed 23:

- `dev:1997`, вопрос о золотом запасе США: выбраны документы «Банк России» и «Дзета Золотой Рыбы»; среди всех доступных кандидатов нет документа с положительной qrel.
- `dev:6227`, вопрос о вступлении США во Вторую мировую войну: выбраны «Шмидт, Рудольф» и «Австралия в Первой мировой войне»; положительно размеченных кандидатов нет.
- `dev:3376`, вопрос о вступлении Италии в Первую мировую войну: выбраны те же два документа; положительно размеченных кандидатов нет.

Эти примеры указывают на потерю содержания вопроса при выборе двух слов и слабость начального поиска; без экспертной проверки текста не следует считать все неразмеченные документы точно нерелевантными. Сокращение вопроса до нескольких слов и отсутствие генерации нового запроса по найденным документам существенно ограничивают перенос к полноценному агентному поиску ВКР.
