# Анализ результатов

Выбранный до теста по validation метод: **reinforce**. Правило: mean validation recall - 0.02 * mean search calls, across seeds; only MARL methods. Тест здесь используется только для описания результатов, а не для выбора.

Для выбранного метода на test: 435 из 450 пар запрос–seed не нашли ни одного размеченного релевантного документа; в 204 из них не выбрано ни одного документа. Это не число различных запросов: один запрос может повторяться для нескольких seed. Строки и ID выбранных документов записаны в error_cases.csv. Неизвестная оценка документа не доказывает его нерелевантность; разбор не устанавливает причину ошибки без чтения текстов.

summary_ci.csv содержит среднее, стандартное отклонение и двусторонний 95% t-интервал по средним независимых запусков: mean ± t(0,975; n−1)·s/√n. Число seed и число запросов указаны отдельно. При n=3 интервал крайне неустойчив, нормальность распределения средних по seed проверить практически невозможно; он не охватывает неопределённость выборки запросов и не подтверждает статистической значимости различий между моделями. Для детерминированного baseline с одним запуском интервал по seed не вычисляется. Интервалы могут выходить за границы допустимых значений метрики. Общее число документов и запросов зависит от сохранённого набора и должно проверяться по паспорту данных.

Графики обучения показывают скользящую среднюю тренировочной награды за 25 эпизодов, а не качество на отложенной выборке. Затраты evaluation_seconds зависят от конкретного оборудования и числа запросов. Сравнение средств и интервалов не заменяет парной проверки различий на общих запросах и дополнительных независимых запусках.
