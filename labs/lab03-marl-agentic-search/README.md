# Лабораторная 3 — кооперативное обучение для агентного поиска

Работа связана с темой ВКР «Разработка языковой модели для многошагового взаимодействия с поисковыми инструментами агентной системы». Два обучаемых агента выбирают поисковые формулировки и свидетельства; максимальный бюджет — четыре поисковых вызова. Сравниваются восемь различных упрощённых алгоритмов, одноагентный PPO и фиксированное распределение действий. Данные — запросы MIRACL-RU и полный индекс на 9 543 918 фрагментов. Это последовательный отбор документов, а не генерация ответа и не проверка способности к multi-hop reasoning.

Методичка содержит обязательные финансовые условия. По сообщению пользователя замена предметной области согласована с преподавателем: OHLCV, портфель и финансовые метрики заменены запросами, документами, поисковым бюджетом и метриками релевантности; равновзвешенный портфель заменён фиксированным поисковым контролем. Буквально финансовые условия не выполняются.

## Воспроизведение

Для расчётов использованы Python 3.10.20 и зависимости из `requirements.txt` (CPU). Нужны исходные topics/qrels из соседней `lab01-llm-miracl/data/raw` и локальный полный FTS5-индекс ВКР, указанный в [паспорте данных](DATA_SOURCES.md). Индекс открывается только для чтения. Результаты из существующего кэша проверяются по SHA-256 перед запуском.

```powershell
cd D:\Projects\University_Current\applied-ml-labs\labs\lab03-marl-agentic-search
D:\Anaconda3\envs\ml\python.exe run_all.py
```

Для пересоздания выборок и выдачи добавить `--refresh-data`; `--skip-report` отключает сборку Word. Получение индекса автоматически не предусмотрено; его происхождение и ограничения описаны в паспорте. Кэш, метки и большие модели не публикуются автоматически. Сборка Word требует bundled runtime Codex; после повторного запуска необходимы экспорт и проверка каждой страницы. См. также журнал `logs/run.log`.

## Состав

- `data_pipeline.py` и `DATA_SOURCES.md` — разбиения, независимые от qrels, полнотекстовый поиск, источники и контрольные суммы; `data/` — локальные подготовленные данные и кэш.
- `environment.py`, `algorithms.py`, `experiment.py`, `config.json` — среда, методы и протокол; `test_environment.py` проверяет бюджет, маску, дедупликацию и отсутствие qrels в наблюдениях.
- `literature.md` — матрица и первоисточники; `analysis_results.py` — таблицы, графики и анализ ошибок.
- `results/` — реальные измерения, прогнозы, сохранённые политики и выбор по validation; `report_lab3.docx` — отчёт, если визуальная проверка завершена.

Оценка теста не является полностью слепой на уровне разработки поиска: до фиксации окончательных правил были просмотрены агрегированные доли пустых выдач предыдущего варианта на test и application без использования меток. Кроме того, официальный dev ранее использовался в ВКР. Результаты относятся к этим отложенным для обучения политикам запросам и не подтверждают качество на новом независимом наборе. Истинная релевантность неразмеченных документов неизвестна, а доверительные интервалы по трём seed ненадёжны.
